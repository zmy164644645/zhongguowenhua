# 春节 · 岁首

一个用于网页制作比赛的春节文化单页，介绍**节日起源、八项年俗、十二生肖、八种吉祥纹样、五则灯谜与五首诗词**，配 10 幅水墨剪纸风插画。

---

## 打开方式

**方式一（推荐）**：双击 `index.html`，并保持同级 `assets/` 文件夹完整。页面无网络依赖，可离线打开。

**方式二**：直接打开 `spring-festival-standalone.html`。所有插画已内嵌为 base64，只需这一个文件即可运行。

---

## 设计概念：一线 · 一窗 · 一印 · 一图

- **一线**：左侧朱砂细线，既是线装书的装订线，也是阅读进度线。
- **一窗**：首屏原创圆形剪纸窗花，中心一个“春”字，载入时描边展开。
- **一印**：朱砂印章式方块，用于章节标记与诗词落款。
- **一图**：10 幅插画作为纸面图版——1 张起源横幅、1 张年兽肖像、8 张年俗方图；统一 1px 细边框与留白，像印在宣纸上的小版画。
- **版式**：12 栏编辑网格、大量留白、细线分隔、竖排诗词；红色只用于点睛。
- **三章新增**：生肖用可点的圆盘（12 个真按钮压在 SVG 环上）、纹样用细线图鉴（8 幅原创 SVG 线描）、灯谜用可揭底的卡片（含一张深色注卡做节奏对比）。三章分别承担「可点、可看、可玩」，避免后半程版式趋同。

### 色板

| Token | 色值 | 用途 |
|---|---|---|
| 宣纸 | `#F5EFE3` | 页面底色 |
| 纸笺 | `#FBF7EF` | 诗词纸笺 |
| 墨 | `#1C1A17` | 正文与标题 |
| 朱砂 | `#A62B1F` | 印章、重点、进度线 |
| 鎏金 | `#C9A227` | 窗花线条装饰 |

正文墨色对比度约 15.2:1，次级文字约 8.3:1，朱砂约 6.1:1；金色与青灰只作装饰，不用于小号正文。

### 字体

全部使用系统字体，不加载网络字体：

- 标题与正文：`Noto Serif SC` / 思源宋体 / 宋体
- 诗词：楷体 / `Noto Serif SC` 回退
- 导航与标签：`Noto Sans SC` / 苹方 / 微软雅黑

## 功能

- **首屏窗花**：原创内联 SVG，12 瓣剪纸纹样，载入时描边展开。
- **起源横幅**：上古岁首祈年场景插画，置于“壹 · 起源”标题下。
- **起源时间线**：上古岁首祈年 → 前 104 年太初历 → 1914 年“春节”定名 → 2006 年国家级非遗 → 2024 年世界非遗。
- **八项年俗**：扫尘、贴春联福字、剪窗花、年夜饭、守岁、拜年、舞龙舞狮、闹元宵；每项配 80–148px 方形插画。
- **生肖轮盘**：十二生肖按 30° 环形排布，点击或方向键切换，联动轮心、地支、近三年公历年份与释义；附十位天干、十二位地支与「一甲子」说明。生肖与十二时辰的对应取自民间通行解释。
- **吉祥纹样**：蝙蝠（福）、鱼（余）、葫芦（福禄）、石榴（多子）、柿子（事）、铜钱（财）、祥云（吉祥）、回纹（绵延）八幅原创线描，逐条标注谐音与用法，并附「福在眼前」「福禄万代」等组合说明。
- **灯谜**：五则字谜与习俗谜（岁岁除夕、一口咬掉牛尾巴、千里相逢、人有了它、一夜连双岁），点「看谜底」揭开谜底与拆字解析，另设一张「别解，才是灯谜」的注卡讲清谜面、谜目、谜底三层结构。
- **年兽肖像**：置于“民间传说”边注上方，与时间线并置。
- **五首诗词**：元日、除夜作、拜年、守岁、除夜雪；桌面竖排纸笺，移动端自动转横排。
- **交互**：章节导航高亮、滚动进度线、诗词 ARIA tabs（方向键 / Home / End）、生肖轮盘（点击 / 方向键 / Home / End，`aria-pressed` + `aria-live` 播报）、灯谜 `aria-expanded` 揭底、进入视口点亮。
- **图标动效**：窗花中心轻微呼吸、悬停时整朵窗花缓慢转动；章节印章进入视口时“落印”；八张年俗图进入视口时从左到右展开；纹样线描进入视口时点入；切换诗词时落款印章盖印。
- **光影**：窗花背后一层暖色灯晕，配一圈 180 秒转一周的放射光，取“剪纸透光”的意思；首屏有 14 粒金屑缓慢上浮。章节分隔线上每 15 秒游走一道高光；朱砂印面（章节序号、落款印、谜底印）每 6–9 秒掠过一道斜向反光；年俗插画进入视口时有一道光带从左扫到右；灯谜暗卡顶部承接一片暖光；描线纹样悬停时生暖色外发光；左侧进度线终点是一颗带光晕的光点。所有光都做在朱砂、鎏金、墨色这些实色上——浅色纸面上加白光几乎看不出，只有落在实色上才成立。
- **响应式**：桌面 / 平板 / 手机三档布局，窄屏下年俗图自动缩为 80px 方形图版。
- **无障碍**：语义结构、跳转链接、键盘焦点、`aria-live` 切换播报、`prefers-reduced-motion` 支持。
- **离线可用**：10 张 WebP 插画均为本地资源；无网络字体、无第三方库、无外部请求。

## 技术说明

- `index.html`：HTML + 内联 CSS + 原生 JS + 内联 SVG + 本地 WebP 插画。
- 图片规格：8 张方图 `600×600`；起源横幅 `1600×900`；年兽 `720×900`；WebP q84。
- 插画使用 `loading="lazy"`、`decoding="async"` 与固定宽高，避免布局偏移。
- 纸纹由内联 SVG `feTurbulence` 生成。
- JS 使用 `IntersectionObserver`、`requestAnimationFrame` 与 ARIA tabs；无复杂依赖。
- `spring-festival-standalone.html`：将 10 张图片以 base64 内嵌，适合只提交一个文件的场景；`assets/source/` 保留原始 PNG/JPG，方便替换或重新压缩。
- `prefers-reduced-motion: reduce` 下所有内容直接呈现，不做入场与切换动画。
- 光效均为纯 CSS（径向/锥形渐变 + `transform`/`opacity`/`background-position`），不加 canvas、不加滤镜链；旋转与呼吸只改 `transform`、`opacity`，避免整层重绘。
